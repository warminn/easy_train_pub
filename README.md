# easy_train_pub

Used to assist with 12306 ticket snatching, after creating a ticket-snatching task, it can automatically snatch tickets.。 用于辅助 12306 抢票，创建抢票任务后可自动抢票。

- **查票**：出发站/到达站/出发日、查询车票、车次列表、预填抢票（跳转抢票 Tab）
- **抢票**：抢票任务列表（以开抢时间「日期+小时分钟」命名）、新建/配置任务、任务执行详情
- **我的**：12306 账号登录（账号、密码、证件号后 4 位、短信验证码）、乘车人列表
